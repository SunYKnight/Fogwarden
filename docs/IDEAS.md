# Ideas

Features not scheduled yet: mostly larger ones (several days each) and deferred decisions. Agreed work is in
`BACKLOG.md`.

| Idea                  | What it would do                                                                                                    | Why it is large                                                                                             |
| --------------------- | ------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Multi-floor maps      | Stacked floors with stairs; tokens change floors, players see the floor they are on, upper floors cut away in 3D.   | Touches the map model, vision (per floor), fog, editor, rendering and the Dungeon Alchemist import.         |
| TV / touch table mode | Player view on a screen lying on the table: top view, touch gestures for moving tokens, rotated UI per seat.        | Needs touch input handling, a new player layout and testing on real hardware.                               |
| German UI             | Language switch in Settings (English / Deutsch); every UI text translated, players' pages follow the DM's language. | Touches every UI file; needs a typed dictionary per area, a glossary and a review pass by a German speaker. |
